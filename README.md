# akim · para comercios

Aplicación web ligera para gestión de comercios. Sin dependencias externas, funciona directamente en el navegador con persistencia en `localStorage`.

## Funcionalidades

- **Dashboard** – resumen del día: ventas, productos y clientes.
- **Productos** – alta, stock y precio de cada artículo.
- **Ventas** – registro de ventas con descuento automático de stock.
- **Clientes** – directorio de clientes del comercio.

## Uso

Abrir `index.html` en cualquier navegador moderno. No requiere servidor ni instalación.
